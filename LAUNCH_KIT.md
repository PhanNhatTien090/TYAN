I've been working on TYAN, my customized edition of ARTEX, as a security software project.

The focus of this edition is the experience around the tools: a terminal-inspired interface, English application UI, English/Vietnamese setup guides, and Windows launch scripts. There's also a tiny hacker mascot. Its only production responsibility is looking busy.

## Reddit / technical community — English

**Title:** Feedback wanted: TYAN, my ARTEX-based local-lab security console customization

I'm the maintainer of TYAN, a customized edition of ARTEX. I'd like feedback on the interface and onboarding documentation.

My changes focus on:

- A dark mint, terminal-inspired interface and English application UI.
- English/Vietnamese feature and setup documentation.
- Windows start/stop scripts for a configured local instance.
- An optional animated mascot, because not every feature needs a CVE.

The underlying project provides an AI-powered research console with task/agent activity, assets, findings, and HTTP evidence. I'm not claiming these underlying capabilities as my original work; ARTEX credits and license notices are retained.

This is not a one-click, configuration-free deployment. You need a database, an LLM provider, and appropriate local tools. Model output needs human verification. Screenshots show sample records, not demonstrated assessment results.

Usage is restricted to learning and research in isolated local labs. Read the full repository restrictions; upstream prohibits testing online/networked systems, even owned or authorized ones.

Repo: https://github.com/PhanNhatTien090/TYAN

Specific feedback I'd appreciate: where do the setup instructions become unclear, and which UI screen needs the most work? Please remove secrets and private data from any shared logs.

## Common questions

**Is TYAN built from scratch?** No. It is a customized edition of ARTEX. See the repository's NOTICE and original documentation.

**Can I use it against a public target with permission?** No. The upstream restrictions limit use to isolated local labs and prohibit online/networked testing even when owned or authorized.

**Are the screenshots real assessment results?** No. They illustrate the interface using sample data.

**Does installation include an LLM service?** No. Configure your provider/model and any required tools separately. Provider costs and data handling depend on your configuration.

**Where should I send feedback?** Use Discussions for ideas and questions, or the bug-report template for reproducible problems. Never post credentials or private evidence.
